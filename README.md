# Loss recovery calculator

A free, offline calculator for the percentage increase required to return to the starting amount after a percentage loss.

Lose50%: the remaining50 must gain100% to return to100. Lose20%: the remaining80 must gain25%. Lose100%: no finite percentage increase of zero restores a positive starting amount.

## Use

Download **loss-recovery-free.zip**, extract it, and double-click **index.html**. The practice page is **worksheet.html**. No installation, account, API key, network request, tracking or payment is required by this tool. Hosting platforms have their own logging/privacy policies. Modern browser required. The optional browser modelContext integration exposes the same visible calculation where supported; it is not required for ordinary use.

Formula: required gain percent = loss / (100 - loss) ×100. Input must be finite and between0and100. This is arithmetic education, not a prediction, trading strategy or investment recommendation. Display rounds to two decimal places.
